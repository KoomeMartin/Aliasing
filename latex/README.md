# Lab 2 report (LaTeX)

- `main.tex`: the report (cover page, setup, results a to g in the order of the handout, attachments).
- `images/`: the figures used by the report. File names start with the handout part they belong to.

| Image | Part | Source |
|---|---|---|
| `b_tone2500.png`, `c_tone5000.png`, `d_tone5000_sub2.png` | b, c, d | `out/` (generated by `experiments/run_lab_experiments.py`) |
| `e_music_spectrograph.png` | e | regenerated from `Music/music_play.wav` with the app's plotting code (N = 512, floor -45 dB) |
| `f_sub2.png`, `f_sub4.png`, `f_sub5.png` | f | `Music/Music_play_spectograph_f{2,4,5}.png` |
| `g_filter4k_sub2.png`, `g_filter2k_sub4.png`, `g_filter1_6k_sub5.png` | g | `Music/Music_play_spectograph_f{2,4,5}_after_filter_*.png` |

Build (any TeX distribution, run from this folder):

    pdflatex main.tex
    pdflatex main.tex     # second run resolves figure and table references

Or upload the `latex/` folder to Overleaf and compile `main.tex`.
